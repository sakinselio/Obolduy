# CAPT / MCL Discord Bot

## Установка
1. Установить Node.js 20+.
2. Выполнить `npm install`.
3. Создать `.env` на основе `.env.example` и указать токен/ID.
4. Запустить `npm start`.

## Что важно
- CAPT теперь можно создавать одновременно в любом количестве. Каждый CAPT имеет свой номер и работает независимо.
- MCL поддерживает несколько одновременно активных MCL и каждый имеет свой номер.
- Старый формат `activeCapt` автоматически мигрируется в список `activeCapts`.
- Кнопки состава привязаны к конкретному CAPT/MCL и выбор игрока хранится отдельно для каждого администратора, поэтому несколько админов могут одновременно управлять разными событиями.
- `/profile` показывает профиль игрока и накопленную статистику.
- Заявки нумеруются и блокируют повторную подачу, пока находятся в обработке.
- Для заявок используется `assets/application.png`.
- Канал `logs` создаётся автоматически.

## Команды
- `/capt время:HH:MM количество:N`
- `/mcl время:HH:MM количество:N`
- `/profile игрок:@user` (игрок необязателен)
